The modular low poly character set of casual cloth. This package is fully compatible with other cloth sets.

The package includes 19 cloth items. Upper cloth splits into sub-parts - torso, sleeves, capes. Source maya scene and other common resources are in free demo npc_casual_00 (bodies, hair, npc_csl_shoe_01, npc_csl_shoe_02)


Texture sizes: 512x512, 1024x512, 1042x1024 Tif

Mesh format: fbx 

Average polygon count: ~3400-4700tris per character (lod0) 

Meshes: 60

Prefabs: 149

Rigging: Yes 

Facial rig: none

Animation: none 

UV mapping: uv0 and uv1

LODs: 0-4 

Types of materials and texture maps: PBR, metallic
